Multi-Area OSPF – Zagros Logistics
CCNA 200-301 lab: multi-area OSPFv2 (Area 0 / 10 / 20) for a headquarters and two branches, with DR/BDR control, point-to-point links, passive interfaces, hello/dead timers and MD5 authentication.
Environment: implemented in PNETLab. PNETLab labs can't be exported as a single file here, so verification screenshots are provided instead of a lab file.
